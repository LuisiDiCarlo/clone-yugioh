# 🚀 Clone Yu-Gi-Oh! Card Slider

> Um carrossel interativo de cartas inspirado no universo Yu-Gi-Oh!, desenvolvido durante a Semana do Zero ao Programador Contratado do Dev em Dobro.

## 📋 Sobre o Projeto

Este projeto foi desenvolvido durante a **Semana do Zero ao Programador Contratado**, evento promovido pelo canal **Dev em Dobro**.

A aplicação consiste em um carrossel de cartas inspirado no jogo e anime Yu-Gi-Oh!, permitindo que o usuário navegue entre diferentes monstros através de botões de navegação. Cada carta apresenta informações como nome, imagem, nível, descrição, ataque e defesa.

Além disso, as cartas podem ser alternadas entre os modos de batalha, simulando o comportamento clássico do jogo, onde uma carta pode ficar em **Modo de Ataque** ou **Modo de Defesa**.

O objetivo principal do projeto foi praticar conceitos fundamentais de desenvolvimento Front-End utilizando HTML, CSS e JavaScript puro.

### Principais Funcionalidades

* ✅ Navegação entre cartas através de um carrossel interativo
* ✅ Exibição de informações detalhadas de cada carta
* ✅ Alternância entre Modo de Ataque e Modo de Defesa
* ✅ Layout responsivo para dispositivos móveis
* ✅ Interface inspirada nas cartas clássicas de Yu-Gi-Oh!
* ✅ Animações e efeitos visuais utilizando CSS

## 📖 Como Utilizar

1. Abra o projeto no navegador.
2. Utilize os botões de seta para navegar entre as cartas.
3. Visualize as informações de cada personagem.
4. Altere o estado da carta clicando nela e entre Modo de Ataque e Modo de Defesa para simular uma partida de Yu-Gi-Oh!.
